Infrastructure
Server deployment & service coexistence
Installed Wazuh all-in-one on a production home server running Jellyfin, Immich, and Caddy via Docker. Resolved port 443 conflict by relocating the dashboard to port 9443 — zero downtime for existing services.
Detection

Practiced the SOC triage cycle: identify → gather context → correlate events → check compliance mapping → classify (true positive / false positive). Documented investigation findings with dashboard evidence.
